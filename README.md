# 가나 1시간 완성 (あ·ア)

히라가나·가타카나의 **발음**을 1시간 안에 외우도록 만든 설치형 웹앱(PWA)입니다.

👉 **바로 사용: https://johun204.github.io/kana-1hour/**

## 학습 방법
| 방법 | 앱에서 하는 일 |
|---|---|
| 🖼 형상 기억 | 92자 전부 "모양 → 그림 → 소리" 이야기 + **글자 모양대로 그린 그림 위에 글자를 덧그린 이미지** (예: `ね` = 꼬리 만 고양이 **네**코, `し` = 낚싯바늘) |
| 🧠 인출 연습 | 카드를 본 직후 퀴즈. 글자마다 2번(글자→소리, 소리→글자) 맞혀야 통과 |
| 🔁 간격 반복 | 3행마다 복습 체크포인트. 틀린 글자는 바로 다시 나오고, 약점 점수로 더 자주 출제 |
| ⚖️ 닮은꼴 구분 | 20개 닮은꼴 묶음(シツ, ソン, クケタ, ぬめ, ねれわ…)마다 **구분 획을 빨간색 + 쓰는 방향 화살표**로 나란히 비교, 핵심 규칙 한 줄("시는 눕고 츠는 선다"), 닮은 글자끼리만 보기로 나오는 구분 훈련, 헷갈려 틀리면 그 자리에서 비교 카드 |
| ▶ 획순 | 모든 글자 획순 애니메이션 (번호 표시) |
| 🔊✍️ 다감각 | 일본어 TTS 발음, 손가락 따라 쓰기 캔버스 |
| 📏 규칙화 | 탁음(゛゜)·요음(ゃゅょ)·촉음(っ)·장음(ー)은 규칙 하나로 처리 |
| ⌨️ 타이핑 테스트 | 최종 테스트는 로마자/한글 직접 입력, 90% 이상 합격 |

## 커리큘럼 (약 60분)
1. **히라가나** — 시작 가이드 → 9개 행 레슨 + 복습 3회 → 탁음·반탁음 → 요음·촉음·장음 + 단어 → 닮은꼴 구분 → 최종 테스트
2. **가타카나** — 히라가나 짝짓기 소개 → 9개 행 + 복습 3회 → 닮은꼴 구분 → 탁음·장음 → 외래어 읽기 → 최종 테스트
3. **마스터 테스트** — 약점 위주 40문제

## 기능
- 오프라인 동작, 홈 화면 설치(Android/데스크톱 설치 버튼, iOS 안내)
- 진도·공부 시간·글자별 정답률 저장(localStorage)
- 50음도 표: 글자별 숙련도 색상, 눌러서 기억법 보기
- 약점 복습: 가장 많이 틀린 글자 15개

빌드 없음 — 정적 파일(`index.html`, `app.js`, `data.js`, `style.css`, `sw.js`)만으로 동작합니다.

## 그림 다시 만들기
`tools/gen_images.js`가 KanjiVG 획을 굵게 그린 시작 이미지를 로컬 이미지 서버(Z-Image Turbo, img2img strength 0.2)에 넣어 글자 모양을 따라가는 그림을 만들고, 그 위에 같은 획을 빨간 선으로 덧그립니다. 주제는 `tools/prompts.js`.
